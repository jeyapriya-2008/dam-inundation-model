Dam Break Inundation Model

Enter a dam name to see its current reservoir status and a simulated downstream flood-spread estimate.

Try: Mettur, Vaigai, Mullaperiyar, Bhavanisagar, Krishnagiri, Stanley Reservoir

Demo data notice: This prototype uses illustrative reservoir figures and a simplified distance-decay model to estimate flood spread — it is built to demonstrate the workflow for the hackathon, not for real flood warning. A production version needs live telemetry (CWC/PWD gauge feeds) and real breach-flow simulation (HEC-RAS or similar) run against terrain elevation (DEM) data.
